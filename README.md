# GitHub Learning Guide

A simple website that teaches Git and GitHub step by step: basics, setup, first repo, branches, pull requests, GitHub Pages, a searchable cheat sheet, and a quick quiz.

Built with plain HTML, CSS and JavaScript. No build step needed.

## Run it

Open `index.html` in your browser.

## Host it free

On GitHub: **Settings → Pages → Branch: main, / (root) → Save**.
